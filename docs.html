GitHub REST API Integration & Docs

Technical overview of how GitHub Achievements Tracker integrates with the official GitHub REST API v3, handles rate limits, and protects user privacy.

1. GitHub API Endpoints Used

All requests send Accept: application/vnd.github+json and X-GitHub-Api-Version: 2022-11-28 directly from the user's browser.

GET /users/{username}

Loads public profile identity, avatar, bio, followers, and user ID for verified noreply co-author email generation.

Profile & Pair
GET /users/{username}/repos?type=owner&per_page=100

Analyzes owned public repositories, top star counts (Starstruck), and primary programming languages (Galaxy Brain Q&A links).

Starstruck
GET /search/issues?q=author:{username}+type:pr+is:merged

Reads the total count of merged public pull requests authored by the user to compute Pull Shark tiers.

Pull Shark
GET /search/issues?q=author:{username}+is:closed

Inspects recent closed issues and pull requests to detect items closed within 5 minutes of creation (Quickdraw).

Quickdraw

2. Privacy & Rate-Limit Model

  • 100% Client-Side: No backend server, no telemetry, and no third-party proxy. Every API call goes directly from your browser to https://api.github.com.
  • Optional Personal Access Token: Public unauthenticated calls allow up to 60 requests/hour per IP (and 10 search requests/minute). Entering a Personal Access Token raises the rate limit to 5,000 requests/hour and stays solely in browser memory for the current tab.
  • Live Rate-Limit Visibility: Remaining quota from x-ratelimit-remaining and x-ratelimit-limit headers is surfaced directly in the dashboard header.
